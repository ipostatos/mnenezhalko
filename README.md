# МнеНеЖалко — Telegram-бот и Mini App

Бот книжного проекта [«МнеНеЖалко» в Польше](https://mnenezhalko.notion.site/in-Poland-e4f29a5687c449f79581add35f17791b):
быстрый доступ к общей библиотеке, поиск, ИИ-подбор книги по настроению,
городские чаты, ближайшие встречи, барахолка и добавление своей книги на полку.

Бот: [@mnenezhalkobot](https://t.me/mnenezhalkobot) · чат проекта: [МнеНеЖалко в Польше](https://t.me/+hlRk_HGIDcE4M2Vi)

Дизайн Mini App — общая дизайн-система ISSA / KwadratPL (Telegram-нативные токены,
тёмная тема по умолчанию, плоские карточки, главная = хаб плашек).

## Данные

Библиотека живёт в публичном Notion проекта. Синхронизация — только на чтение,
через публичный `api/v3/queryCollection` (интеграционный токен не нужен):

- **КНИГИ** — 3 237 записей: название, автор, жанры, язык, обложка, владелец;
- **Библиотекари** — 141 человек: имя, город/район, Telegram, Instagram;
- **Настольные игры** — 12 записей.

Сервер Notion отдаёт максимум 1000 строк за запрос, поэтому книги забираются
рекурсивным делением диапазона «Date added» пополам (`server/src/notion.ts`).
Города приводятся к единому списку (`Gdańsk`/`Gdynia` → `Trójmiasto` и т. п.).

Полный синк занимает ~60 секунд, повторяется по расписанию
(`NOTION_SYNC_HOURS`, по умолчанию 12 ч), вручную — `npm run sync` или `/sync` от админа.
Книги, добавленные через бота (`source = bot`), синком не затираются.

## Как книга попадает в общую таблицу

[Инструкция новичка](https://mnenezhalko.notion.site/3fcdfa8ed57444d7ae2129bf5c0299f7)
просит человека завести себя в **Owners**, а книгу — в **All Books** (настолку —
в **Board Games**), войдя в Notion по почте. Бот делает это за него:

1. фото обложки → Claude vision → название, автор, язык, жанры
   (жанры и языки строго из справочников Notion, иначе multi-select засорится);
2. если библиотекаря ещё нет в Owners — заводится карточка с городом/районом
   («Warszawa/Wola» — город книги в All Books считается rollup'ом от владельца)
   и ссылкой на Telegram;
3. книга уходит строкой в All Books с обложкой-ссылкой `/api/cover/…`
   (то же «Embed link» из инструкции) и двусторонней связью с владельцем;
4. параллельно карточка живёт у нас, поэтому в поиске видна сразу.

Таблицы расшарены публичной ссылкой с правом `read_and_write`, но анонимно
Notion писать не даёт (`saveTransactions` → 401), поэтому нужен `NOTION_TOKEN_V2` —
cookie аккаунта, открывшего эту ссылку. Без токена или при сбое карточка остаётся
со статусом `pending`, админам приходит уведомление, дожать — `/notionpush`.

Проверить канал записи: `npm run notion:check -w server` — заводит тестовые строки
в Owners и All Books, читает их обратно и архивирует.

## Чат проекта: темы, афиши, барахолка

Общий чат — супергруппа `-1001856176764` с темами по городам. Их id зашиты
в `server/src/seed.ts` и заводятся при старте (идемпотентно, по url):

| Тема | id | Что делает бот |
|---|---|---|
| Warszawa 3637, Trójmiasto 3638, Kraków 3639, Wrocław 3640, Poznań 3641, Łódź 3642, Olsztyn 4875, Białystok 6999 | — | ссылки в `/groups` и в Mini App |
| Афиша встреч | 14501 | разбирает анонс (город, дата, место), заводит встречу, шлёт алерт подписчикам |
| Барахолка | 4547 | превращает пост с фото в карточку: тип, цена, город, кому написать |

⚠️ Чтобы это работало, бот должен быть **участником группы** и **видеть сообщения**:
добавить @mnenezhalkobot в чат и либо выключить privacy mode
(@BotFather → `/setprivacy` → Disable), либо сделать бота администратором.
Пока бота нет в группе, темы просто показываются ссылками.

Анонсы приходят тем, у кого совпадает город (или город не выбран),
выключаются командой `/alerts`. Дубли отсекаются по id сообщения-афиши.

## Стек

- `server` — TypeScript, Fastify 5, grammY, Prisma + SQLite, `@anthropic-ai/sdk`
- `web` — React 18 + Vite, Telegram WebApp SDK, дизайн-система ISSA
- один процесс отдаёт и API, и собранный Mini App

## Запуск локально

```bash
cp .env.example .env      # заполнить BOT_TOKEN
npm install
npm run db:generate
npm run db:push -w server # создать SQLite-базу
npm run sync              # первичный импорт из Notion (~1 мин)
npm run build -w web      # собрать Mini App
npm run dev               # сервер + бот (long polling)
```

Mini App при разработке удобнее гонять отдельно: `npm run dev:web` (проксирует `/api` на 8080).

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | токен бота |
| `PUBLIC_URL` | публичный HTTPS-адрес Mini App (нужен для кнопки и webhook) |
| `BOT_MODE` | `polling` локально, `webhook` в проде |
| `DATABASE_URL` | путь к SQLite |
| `ANTHROPIC_API_KEY` | без него ИИ-подбор деградирует до обычного поиска по словам, а распознавание фото отключается |
| `NOTION_TOKEN_V2` | cookie аккаунта Notion — без неё книги не уходят в общую таблицу |
| `ANTHROPIC_MODEL` | по умолчанию `claude-opus-4-8` (полный подбор ~15–20 с); для более быстрых ответов — `claude-sonnet-5` или `claude-haiku-4-5` |
| `ADMIN_IDS` | Telegram id админов через запятую (`/sync`, `/addgroup`, `/addevent`) |
| `NOTION_*` | id коллекций и вью Notion (значения по умолчанию уже верные) |

## Админские команды

```
/sync                                              — синхронизация с Notion
/notion                                            — состояние канала записи и очередь
/notionpush                                        — дожать карточки в общую таблицу
/addevent Warszawa | 2026-08-01 18:30 | …          — встреча вручную + рассылка анонса
/addgroup Kraków | Книжный Краков | https://t.me/… — ссылка на городской чат
/addevent Warszawa | 2026-08-01 18:30 | Книжный обмен | Кафе «Ластовка»
```

## Как устроен ИИ-подбор

1. Свободный текст → структурированный запрос (жанры строго из справочника, ключевые
   слова, язык) — structured outputs, `output_config.format`.
2. Кандидаты из базы по каждому жанру и слову → второй вызов выбирает до 5 книг
   и пишет, почему они подходят.
3. Ответ — карточки с контактом владельца.

Без ключа шаги 1–2 пропускаются, работает обычный поиск по словам.

## Деплой

`scripts/deploy.sh` — выкладка на VPS через `git archive | ssh` (см. комментарии в файле).
На сервере: `BOT_MODE=webhook`, `PUBLIC_URL=https://…`, systemd-юнит `mnenezhalko`.
