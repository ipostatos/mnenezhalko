CDN внутри запроса пользователя, `/api/photo` был открытым прокси. Все
приоритеты P0–P4 плана выполнены: 19 коммитов, 5 миграций, тестов 132 → 208.

## 5. Data integrity

- busy after sync: сохраняется (тест + прод-смоук);
- города книг/библиотекарей после sync: не обнуляются (тесты);
- deleted resurrection: невозможно (tombstone), недоархивированное дожимает flushPending;
- moderation duplicates: одна строка Notion на книгу (атомарный claim + stable id);
- loan binding: только по токену/проверенному tgId; старые ники нормализованы миграцией.

## 6. Security

- `/api/photo`: подпись сервера (HMAC), rate limit per-IP+глобальный, таймауты 10/15 с, обрыв чтения >5 МБ, фактический декод + webp (срезает EXIF/GPS), в логах нет токена и file URL;
- авторизация остальных ручек — без изменений (initData), контакты только по подписи (privacy.test);
- coverUrl: только http(s) на публичный хост (SSRF-фильтр), мусор — 400;
- произвольный city больше не раздувает SyncState/кэш;
- rate limits на платных и внешних ручках — без изменений, /api/photo добавлен.
